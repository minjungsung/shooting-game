# Shooting Game

> Unity 2D 종스크롤 슈팅 게임

## 게임 개요

전통적인 아케이드 스타일의 2D 종스크롤 슈팅 게임입니다. 플레이어는 아래에서 위로 이동하며 다양한 적을 물리치고, 보스전을 클리어해 스테이지를 진행합니다.

### 게임 메카닉

#### 플레이어 시스템

- **이동**: 화면 내 자유 이동 (상하좌우 경계 충돌 감지)
- **공격**: Fire1 버튼으로 발사 (자동 연사, 딜레이 기반)
- **파워업**: 아이템 획득으로 공격력 강화 (maxPower까지)
- **폭탄**: 특수 폭탄 공격 (maxBoom까지 보유)
- **생명**: 피격 시 생명 감소, 무적 시간(3초) 부여
- **팔로워**: 보조 공격 유닛 (파워업으로 활성화)

#### 적 유형

| 타입 | 이름 | 체력 | 특징 |
|------|------|------|------|
| S | Small | 3 | 약한 적, 빠른 출현 |
| M | Medium | 10 | 중간 적 |
| L | Large | 40 | 강한 적, 높은 체력 |
| Boss | Boss | 100 | 스테이지 보스, 패턴 공격 |

#### 아이템 시스템

| 아이템 | 효과 |
|--------|------|
| Power | 공격력 강화 |
| Boom | 폭탄 추가 |
| Coin | 점수 획득 |

#### 보스 패턴

보스는 `patternIndex`와 `maxPatternCount[]` 배열 기반의 다단계 공격 패턴을 가집니다. 각 패턴이 끝나면 다음 패턴으로 전환됩니다.

### 스테이지 시스템

- CSV 기반 스폰 데이터 (`Resources/Stage X.txt`)
- 각 라인: `delay,type,point` (스폰 딜레이, 적 타입, 스폰 포인트)
- 스폰 리스트 소진 시 보스 등장 → 클리어 시 다음 스테이지

### 프로젝트 구조

```
shooting-game/
├── Player.cs           # 플레이어 조작, 공격, 피격
├── Enemy.cs            # 적 AI, 패턴, 드롭
├── Bullet.cs           # 총알 이동 및 충돌
├── Item.cs             # 아이템 물리 및 타입
├── GameManager.cs      # 게임 흐름, 스폰, UI
├── ObjectManager.cs    # 오브젝트 풀링 시스템
├── Follower.cs         # 보조 공격 유닛
├── Explosion.cs        # 폭발 이펙트 애니메이션
├── Background.cs       # 배경 무한 스크롤
└── Spawn.cs            # 스폰 데이터 클래스
```

### 점수 시스템

적 처치 시 `enemyScore`만큼 점수 획득. UI의 `scoreText`에 실시간 반영. 게임 오버 시 최종 점수 표시.
